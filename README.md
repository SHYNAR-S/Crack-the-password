## About

PASSWORD is a browser game where you try to crack a hidden password.

Every round gives you a randomly generated password with a different length. Your goal is to figure it out using the clues from each attempt.

The password can contain letters, numbers and special characters, so you never know exactly what you are going to get.

## How It Works

Enter your guess and submit it.

The game checks every character against the hidden password.

* **Green** — the character is correct and in the correct position.
* **Yellow** — the character exists in the password, but is in the wrong position.
* **Gray** — the character does not appear in the password.

The position matters. Finding the right character is only half the job.

Passwords are always at least 8 characters long and may contain:

```text
A-Z
a-z
0-9
! @ # $ % & * ?
```

The length changes from round to round, and every new game generates a different password.

## Rules

Your guess must have the same number of characters as the hidden password.

You have a limited number of attempts to crack it.

Guess the entire password correctly and you clear the round.

Run out of attempts and the password is revealed.

## The Goal

Crack the password before you run out of attempts.

Simple idea. Not always a simple password.
